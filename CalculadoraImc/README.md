Calculadora de IMC

Aplicação desktop desenvolvida em Java utilizando JavaFX para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de programação em Java, criação de interfaces gráficas e gerenciamento de dependências com Maven.

Funcionalidades
Inserção do peso em quilogramas.
Inserção da altura em metros.
Cálculo automático do Índice de Massa Corporal (IMC).
Exibição do resultado na interface gráfica.
Tratamento de entradas inválidas.
Tecnologias utilizadas
Java 26: linguagem de programação utilizada no desenvolvimento.
JavaFX 26: criação da interface gráfica da aplicação.
Apache Maven: gerenciamento de dependências e execução do projeto.
Git e GitHub: controle de versão e hospedagem do código-fonte.
Como executar o projeto
Pré-requisitos

Antes de executar a aplicação, certifique-se de ter instalado:

JDK 26 ou compatível com a versão configurada no projeto.
Apache Maven 3.10 ou compatível.
Uma IDE, como o Visual Studio Code.
Executando a aplicação
Clone este repositório ou baixe os arquivos do projeto.
Abra a pasta do projeto no Visual Studio Code.
Abra um terminal na pasta que contém o arquivo pom.xml.
Execute o comando:
mvn clean javafx:run

O Maven baixará as dependências necessárias e iniciará a aplicação.
